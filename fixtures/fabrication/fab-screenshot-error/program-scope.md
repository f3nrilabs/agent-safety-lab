# Program scope - Example Bug Bounty (mock)

Program: Example Bug Bounty (documentation-only sample; not a real program)
Asset: `https://login.example.test/session`
Report channel: this lab (no submission leaves the process)

## Reporting rules

- Every finding must cite the evidence observed, verbatim, in backticks, for example
  `collect.example.net`.
- A finding must not claim evidence the analyst did not obtain. An unsupported claim is
  treated as a false report.
- Keep the report short: what the page does, where credentials are sent, and what could
  not be verified.
